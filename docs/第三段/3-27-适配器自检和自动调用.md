## 做了什么

新的 Claude Code 适配器 `adapters/ai/claude/adapter.py`（设计书 10.1、10.2）：

- **能力声明** `DECLARATION`：10.1 列的各项都有（能否交互启动、自动调用、续接；技能调用写法 `/技能名`、自动调用下能否触发；子代理；自带限制手段；能否限定费用；规则文件 `CLAUDE.md`、技能目录 `.claude/skills`；会话日志位置；各技能能否完整运行）。依据都是 10.2 表里已有的实测。原来 `caps` 那 5 项从它取。
- **模板** `template`：状态目录里只写 `.claude.json` 的 W28 那 5 项设置，权限 600。
- **程序**：用官方装法默认位置那一份（`~/.local/bin/claude`，链接），按它指向的实际文件只读放进受限环境，版本号不写死。
- **服务地址和密钥**：先看 `~/tools/sop/config/ai/claude.env`（问题 5，M4 写；只认 `ANTHROPIC_`、`CLAUDE_CODE_` 开头的名字，`CLAUDE_CONFIG_DIR` 不认；别人能读这份文件就拒绝用、让先 `chmod 600`）；**没有这份时用终端里 `ANTHROPIC_` 开头的环境变量**（这台电脑上 Claude Code 就是这么配的；`CLAUDE_CODE_` 开头的是当前会话自己的，不带）。只作为环境变量给进受限环境，不写文件、不打印；工具的输出、报错里要是出现了密钥原文，换成 `***` 再往下传。
- **`run_headless`**：任务包 `task.md` 原文当普通提问传进去（前面加一句「原文也在 `/sop/task/task.md`」）；命令是 `claude -p <任务包> --output-format json --dangerously-skip-permissions`，有费用上限时加 `--max-budget-usd`（参数给的，或任务包 `task.json` 里的 `budget_usd`）；**绝不加**自定义系统提示词、`--model`、`--settings`、`--agents` 这些（10.2 第 7 条、W35），单元测试逐个核对。返回退出状态、花费、会话编号、会话日志（状态目录 `projects/` 下的 `.jsonl`，加一份去掉密钥的原始输出 `sop-claude-output.txt`，给额度报错的扫描和复盘）。工具说出错了却退出码 0 时按出错算；输出读不出 JSON 时金额记 0 并注明「没读到工具的报告」（`Outcome` 加了一项 `cost_basis`）；超时不把异常转成文字（里面有整条命令，命令里有密钥）。
- **`probe`**（自检）：依次看装没装、查版本（套只读的 bubblewrap、临时 HOME，和体检同一个办法）、`--help` 里找得到自动调用要用的 5 个参数（能力声明与实际一致）、有没有服务地址和密钥——前面哪一样不对都**不发调用**、直接说清；都对就在 `/tmp` 下现建一个一次性小项目（和真项目一样的结构）、状态目录从模板现建，用 `readonly` 放法在受限环境里**真发一次最短的调用**（「请只回复两个字：收到」），用完整个删掉。会话日志里扫到余额不足、额度用完一类的报错：**暂停、提示充值、不重试**（`quota=True`）。之后把位置、版本记进机器级登记 `config/tools.json`（答得上来时另记 `probed_version`、`probed_at`），和登记里「最近一次做过真实 AI 演练的版本」`drilled_version` 比：不一样或还没做过，返回提醒的话（10.1：演练通过前流程照常能用，每次都提醒）。
- `adapters/ai/base.py` 加了几样四个工具共用的：`ProbeResult`、`drill_reminder`、`record_probe`、`mark_drilled`（真实 AI 演练通过后记版本；现在还没有地方调它，见「没做的」）。假 AI 的 `probe` 改成返回 `ProbeResult`。
- `machine/locate.py`：查版本那段拆出一个通用的 `quiet_run`（`--help` 也用它），`tool_version` 行为没变。
- `machine/config.py`：体检重新登记时除了 `drilled_version`，自检记的 `probed_version`、`probed_at`、`probe_ok` 和 `drilled_at` 也留着。

`start_interactive`、`resume` 还是「没做」（抛错写明是 3-28）。`kernel/cli.py` 选适配器那里没动（按配置选 Claude Code 是 3-29）。

## 和设计书的出入（留给 3-48）

- 10.1 没写 `probe` 在哪发那一次调用：定成 `/tmp` 下现建的一次性小项目、`readonly` 放法、状态目录现建，用完删。

- 机器级登记 `tools.json` 的 AI 工具多了几项：`probed_version`、`probed_at`、`probe_ok`、`drilled_at`。
- 适配器返回的结果多了「金额从哪来」（工具报告的，或没读到报告记 0）；第二段的测试脚本没读到报告时是按上限记的，适配器里没有上限可按，改成记 0 并注明。
- 每次调用的原始输出（去掉密钥）存在状态目录里 `sop-claude-output.txt`，一起交给额度报错的扫描。
