### Q4 的做法

1. **空间不够不开始**：备份位置要放下所有选了带走的镜像和卷；新 Docker 的数据目录（`~/tools/docker/data`）要再放一份，外加最大那个卷还原时的临时卷；各多留 1 GB。两处在同一个分区上就合起来算。不够就说「要多少、剩多少、还差多少」，建议腾空间、换备份位置（`--backup-dir`）或少带几样；有量不出大小的也不开始。默认备份位置 `~/tools/backup/migrate-<日期>/`（权限 700）。
2. **新 Docker 里已经有同名的数据卷、又不是这次迁移建的**：不覆盖，停下说清楚（这时旧的还一样没动）。
3. **打包用的小镜像** `alpine:3.20`（第一段 W27 用它两种装法都走通过）：新 Docker 里没有就下载；旧 Docker 里没有就从新的那份导过去，**用完删掉**（先记进记录，断了下次 `sop` 删）。
4. **镜像**：`docker save` 从旧的导出到备份位置（从命令的输出接出来，由小白自己的账号写文件），再 `docker load` 进新的。
5. **数据卷**：
   - 先问一句「要打包的数据卷正被容器 X 用着……先停一下，打完包马上起回来」（默认不停；不停就不做）。
   - **停容器之前先写记录** `config/migrate/stopped.json`（停了哪几个、在哪份 Docker、怎么连；写完先落盘）。
   - 停掉所有正在用这些卷的旧容器 → 每个卷在旧 Docker 里用一个用完就删的临时容器打包（`tar --numeric-owner -cpf -`，包从容器的标准输出接出来写成备份文件）、算一份文件清单 → **马上把容器起回来**、从记录里去掉。任何一步出错也先起回来。
   - 然后在新 Docker 里：建临时卷 `sop-migrate-try-<卷名>`、把包解进去、算清单，和打包时的比；**对不上就停下**（列出哪几行不一样、两份清单在哪），旧的照常可用；对上了删掉临时卷，建同名的新卷（带上原来的标签，编排工具认得出是自己的卷）、解进去。
6. 做到哪一步记在 `carry.json`，断了再执行一次接着做，做完的跳过。

**文件清单**算的是：每样东西的路径、类型、归属（容器里看的编号）、权限；每个文件的校验值（sha256）；每个链接指向哪。**不比目录的大小**：同样的目录在不同文件系统上大小不一样（旧的在系统盘、新的在主目录分区时会误报）。清单在临时容器里用 alpine 自带的 busybox 算，旧的新的用同一个小镜像，输出格式一样。

**不往旧 Docker 里挂宿主机的目录**（第一段原型是 `-v 备份目录:/to`）：系统自带的 Docker 的容器以真管理员写文件，挂目录会留下属于管理员的备份文件，小白自己删不掉；改成从容器的标准输出、标准输入接，进出都是小白自己的文件。

### `sop` 每次启动先看记录

`kernel/cli.py` 的入口：除了 `sop machine migrate` 自己（它一开始也先做同样的事），**任何 `sop` 命令**一开始都调 `record.recover()`：

- 没有记录就什么都不做（只看一个文件在不在）；
- 有记录：先说一句「上次环境迁移时……停掉了旧 Docker 里的容器 X，迁移没走完就断了。现在先把它们起回来」，要管理员的先说「系统会问一次登录密码」，再 `docker start`；临时放进旧 Docker 的小镜像也删掉；都做好了才删记录；
- 没起回来：说清楚、给出自己执行的命令、记录留着下次再试，**不挡这次要做的事**；记录读不懂：如实说、不猜；
- 迁移正在另一个终端里进行时（`running.lock` 文件锁，进程怎么死都由系统放开）不去起，不然正在打包的卷会被写；同一时刻只能有一个迁移。

## 替用户定的（可否决）

3-30 留下的两件，按「默认不动用户的东西、先说一句再 sudo」定：

1. **旧的 Docker 停着时，要不要先把它起来再列**：清点（Q1）照旧不连它（系统自带的那种一连就会被系统自动起来）。**只有小白在 Q3 选了「卸掉」这一份**、要列出里面的数据卷让他选带不带走时，才先说一句为什么（「得先把它起来，只是起来，里面的东西一样不动；迁移结束时再把它停回去」，系统自带的还说要管理员密码），再问「现在把它起来吗」，**默认不起**。不起就把这一份改回「留着」（不知道里面有什么，就不能卸）。起了的，迁移结束时——做完或中途停下都算——把它停回去（只停 `docker.service`，原来在听的通道 `docker.socket` 不动）。免管理员那种用 `systemctl --user start docker.service`；没登记成后台服务的不知道怎么起，让小白自己起。
   - 代价：选「卸」又不肯起的，这一次卸不了；sop 在起着旧 Docker 的时候被强制结束，旧 Docker 会一直开着（没记进记录，开着是它平常的样子，不影响什么）。
2. **什么时候让小白输管理员密码**：一开始不问。清点不用管理员也做得了（系统盘上的目录量不全就写「至少多大」；`--admin` 才一开始就用）。只在真要用的那一步之前先说一句为什么，再由系统问：
   - 选了卸系统自带的 Docker、而小白不在 docker 组（不用管理员连不上它）：说明要列出、要打包都得用管理员权限，「只看、只打包，不改里面的东西」，问「现在用管理员权限吗」，**默认不用**，不用就改回「留着」；用了之后，Q4 对旧 Docker 的每条 docker 命令前面加 sudo（sudo 自己会记住几分钟，一般只问一次）；新 Docker 从来不用；
   - 起停系统的 Docker 服务时（上面第 1 条）；
   - Q2 要装系统软件包时（M2 自己会先说一句）；
   - 记录里写着「旧的要管理员」时，下次 `sop` 起回容器前先说一句。

另外几处小的（也可否决）：选了卸的 Docker，数据卷和镜像默认「带走」（拿不准的不丢）；停容器前要小白点头、默认不停；一份旧 Docker 里要停的容器一次停完、全部卷打完包一起起回来（同一个项目的数据库和文件卷是同一时刻的样子；停的时间是打包的时间，不含往新 Docker 里还原）；备份不自动删。

## 结果

- 单元测试 434 → 463 项（新 `tests/unit/test_migrate_carry.py` 29 项），流程沙箱 43 个剧本，总检查 95 个样例，全部通过（见下「全部自测」）。
- 假的 docker `tests/fakes/docker/docker`：所有状态在 `FAKEDOCKER_ROOT` 指的测试临时目录里，没设就拒绝运行；旧的、新的按 `--host` 分开；数据卷就是目录，临时容器里的 `tar`、算清单的脚本把挂载点换成目录后在本机跑；能故意出错（某条命令失败、某条命令时把调用它的进程 `kill -9`、还原出来多一个字节、停容器时记录必须已经在）。假的 sudo `tests/fakes/docker/sudo` 不提权，只肯执行假的 docker。
- 测到的（都在临时目录、临时主目录里）：
  - 全默认：一条 docker 命令都没跑，什么都没建；不在终端里按默认；
  - 全带走：新 Docker 里两个卷和旧的逐个文件一样（内容、权限、链接、带空格的文件名），旧的一样没动，标签带上了，临时卷删了，镜像在；**停容器的那一刻记录已经在**（假 docker 核对）；停、两个打包、起回来的先后对；原来停着的容器没去起；临时放进旧的小镜像删了、旧的本来就有的不删；备份文件在、目录 700；
  - 只带一部分：不要的卷、镜像没过去，没名字的镜像说明不带；
  - 不肯停容器：什么都没打包；
  - 打包第二个卷时出错：容器起回来了、记录删了、小镜像删了、新的里一个卷都没放；去掉故障再执行一次接着做完，镜像不重复导；
  - 试还原对不上：停下、说哪几行不一样，新的里没留下卷和临时卷，`ready_for_q6` 没记；
  - 新的里已有同名卷：不覆盖，旧的连一条停、打包、导出都没做；
  - 空间不够：说还差多少，一条 docker 命令都没跑、备份目录没建；两个分区时分开算；量不出大小不开始；
  - 做完再执行：全部跳过；Q5 抓得到新卷被改过；
  - **sop 被 `kill -9`**（打包第二个卷时，另起的进程）：记录留着、容器停着；接着执行一次 `sop machine tools`：先说一句、把容器起回来、删掉小镜像、删记录，再列工具；
  - 没有记录：什么都不做、连目录都不建；迁移正在进行时别的 `sop` 不去起；起不回来时说清楚、给命令、记录留着；记录读不懂如实说；
  - 替用户定的两条：停着的默认不起、改回留，一条命令没跑；起了的结束时停回去（中途出错也停回去）；要管理员的默认不用、改回留、假 sudo 没被调；用了的只有旧的那份走 sudo；
  - Q2：缺 Docker 时连同 uidmap、dbus-user-session 一起装；都合格跳过；缺 wt 让先执行 setup；Q2 不过就停在 Q3 之前。
- 算清单的那段脚本在本机 `/tmp` 的临时目录里用 Ubuntu 自带的 busybox 1.37 跑过一遍（`sort -z`、`xargs -0 -r`、`stat -c '%n|%F|%u:%g|%a'`、`readlink` 都认），**没在真的 alpine:3.20 容器里跑过**，留给 3-33。
