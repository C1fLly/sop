## 造工具包本身要花多少（W30 的粗估）

设计书要求第一段结束时给一个粗估区间。如实说能给到哪一步：

- 工具包的记账只记「试验里调用 AI」的钱，第一段是 1.90 美元。
- **写设计、做试验的这个窗口（Claude Code 的对话本身）花的钱，工具包的记账看不到**，它才是大头。要请用户到服务后台看这几天的实际扣费（见下面的清单第 2 条），才能按「第一段这个窗口一共花了多少」来推后面。
- 后面的工作量，按设计书第 19 节粗数：第 1 期第二、三段（内核、受限运行器、检查库、机器层、Claude Code 适配器）是写代码的大头；第 2a 到 2c 期每期要用真的 AI 做几个功能来验收，按第 20 节的附表每个功能 21 到 41 美元起（真实项目多半更贵），2a 一个、2b 三个、2c 一个，约 100 到 300 美元；第 3、4、5 期再各一些。
- 在拿到窗口实际花费之前，只能给一个很粗的区间：**几百到两千多美元**。这是推测，没有依据把它收窄；拿到后台的数之后，下一个会话照「窗口每天花多少 × 后面还要多少天 + 验收用的 AI 花费」重算一次。
