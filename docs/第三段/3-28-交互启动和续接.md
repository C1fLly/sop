# 3-28 适配器：交互启动和续接

2026-11-21，主控窗口派的子代理做的。没动隔离（受限环境的放法 `runner/placement.py`、`runner/sandbox.py` 一个字没改，对话方式用的就是原来的「不脱离终端」那一种）；没碰 GitHub；**真实调用 4 次，0.0535 美元**（其中一次只打开窗口、不发消息，按 0 记）。

## 做了什么

Claude Code 适配器 `adapters/ai/claude/adapter.py` 补上 10.1 剩下的两个操作，另加一样 3-27 留下的自检：

- **`start_interactive`**（对话方式）：在受限环境里不脱离终端地打开 `claude --dangerously-skip-permissions <开场内容>`，开场内容就是任务包原文（前面一句「原文也在 `/sop/task/task.md`」）；状态目录由调用方从模板现建（3-27 的 5 项设置），所以打开就是输入框；不加自定义系统提示词、模型、设置、钩子。等小白在窗口里 `/exit` 才返回。不在终端里（放法不是对话方式，或标准输入不是终端）就不调用、直接说「要在终端里执行 sop」。小白在外面按 Ctrl-C 时照常收尾。
- **`resume`**（续接并送入补充说明）：`--resume <会话编号>`，第一句是补充说明，后面跟着这一步的任务包（同一个会话组里下一步有自己的任务包）。对话步骤（放法是对话方式）打开对话窗口接着聊；自动步骤用 `-p` 接着跑（费用上限照 `task.json` 的 `budget_usd`）。
- **会话编号和花费**：对话窗口不报 JSON。会话编号取这次写过的会话日志的文件名（续接时还是原来那个编号，实测）；花费取会话日志里 Claude Code 自己记的 `cost-state`（`totalCostUSD`），没有再取状态目录 `.claude.json` 里记着这个会话的 `lastCost`（W28 在 2.1.327 上看到的那处；**2.1.329 没记在工作目录名下**，实测）。
- **续接只记增量**：Claude Code 续接后报的是整个会话的累计数（对话方式和 `-p` 都是，这次实测坐实）。适配器把每个会话到现在的累计数记在状态目录旁边的 `<状态目录名>.sop-cost.json`（受限环境里只放进状态目录本身，AI 看不到、改不了这份），续接时报「这次的累计 − 上次的累计」；上次的数没记下（会话不是经适配器开的）就先看工具自己记的，再没有就按累计数记，宁多不少，`cost_basis` 里注明。
- **`check_screens`**（打开对话窗口不出首次启动的那几屏）：W28 说设置名是 Claude Code 自己定的、升级后可能变，3-27 把「版本变了以后重试一次打开对话窗口」留给了这里。在 `/tmp` 现建的一次性小项目里、从模板现建的状态目录、新写的模拟终端里打开一次对话窗口，**不发任何消息**，看屏幕上出没出首次启动的那几屏（选配色、安全提示、是否信任这个文件夹、「不逐条询问」模式的警告，比对英文原句，去掉空白比），出了输入框就 `/exit`，用完整个删掉。**接进了 `probe`**：最短的那次调用成功之后跑它，出了那几屏或打不开就算自检不通过、说「多半是升级后设置名变了，先交维修窗口」；内核没禁用往终端塞按键时不核对、只说一句。
- **模拟终端** `adapters/ai/ptyscreen.py`（新，只用标准库，照 S9 的 `ptydrive.py` 改的）：给一个命令或一个函数配一个假终端，等屏幕上出现某样东西、打字、记下屏幕上出现过的文字；认得首次启动的那几屏和「可以打字了」（输入框下面那行 `⏵⏵ bypass permissions on`，和警告那一屏的 `Bypass Permissions mode` 大小写不同）。自检、单元测试、真实调用脚本都用它；**小白真用时对话窗口开在他自己的终端里，不经过它**。

## 自测（不花钱）

- 假的 `claude`（`tests/fakes/claude/claude`）加了对话窗口：模板少了哪项设置就先出对应的那一屏（信任和警告那两屏按默认的「不，退出」退出），都有就直接出输入框；命令行最后的开场内容当第一句话；`--resume` 接着原来那份会话日志、记得前文（问「暗号是什么」就从前面的话里找「」里的字）；每回答一次 0.0123 美元，报累计数；退出时记 `cost-state` 和 `.claude.json`，和真的一样。`-p` 的老表现都没变（3-27 的 22 项照样过）。
- 单元测试 `tests/unit/test_claude_interactive.py` 11 项，都在真的 bubblewrap 和模拟终端里跑：开场内容是任务包、屏幕上没有那几屏、命令里没有 `-p` 和禁用的参数、受限环境里只有假密钥和 `TERM`、外面会话的变量一个没带；续接后会话编号不变、记得暗号、只记增量、这一步的任务包跟着送进去；窗口里多说几句花费对；不在终端里不调用；窗口里碰到余额不足，额度扫描抓得到；**反着试**：模板去掉「警告已接受」「引导已做过」「信任这个目录」各一项，模拟终端都认出了对应的那一屏、也没出输入框；`check_screens`、`probe` 好的过、少设置的不过；自动调用的续接记得前文、只记增量、续接前的累计数没记下时按累计数记并注明、续接失败不记钱；`.claude.json` 那条退路；屏幕文字被光标移动打散时仍认得出。
- 全部自测：单元测试 371 → 382 项，流程沙箱 42 个剧本，总检查 95 个样例，全部通过（见下）。**全部自测里没有会真调 AI 的测试**，真实调用在 `tests/real_ai/claude_interactive.py`，它加 `--fake` 时用假的 claude 把自己走一遍（不花钱，记账写到临时目录），真调之前先这样走通了。

## 和设计书的出入（留给 3-48）

- 10.1 `probe`：多了「打开一次对话窗口、不发消息，看首次启动的那几屏出没出」，每次自检都做（约 3 秒，实测不花钱），不只在版本变了时。
- 10.1 `resume`：对话步骤打开对话窗口接着聊，自动步骤用 `-p`；第一句是补充说明加上这一步的任务包。
- 对话方式的会话编号、花费从哪取：会话日志的文件名和 `cost-state`；`.claude.json` 的 `lastCost` 是退路（W28 写的那处在 2.1.329 上工作目录名下没有）。交接里「对话窗口的花费要从状态目录里取、手工记账」现在由适配器自动取。
- 续接只记增量：适配器在状态目录旁边记每个会话的累计数（`<状态目录名>.sop-cost.json`），状态目录本身之外多了这一份小文件。

## 自己出的错

- 模拟终端的 `close()` 一开始不能重复调用：`with` 结束时又调一次，把已经读到的结果清掉了，单元测试第一遍因此失败，改成第二次什么都不做。
- 假的 claude 续接时把会话日志里 `cost-state` 那一行也当成一句对话去显示，报错；改成只显示回答。
- 真实调用脚本把 A 的「金额从哪来」写错（见上），记账已改正。
- 摸底时在 377 MB 的 claude 程序文件上用 `grep -o '.\{400\}…'` 找字，太慢，两分钟没完，停掉改用 Python 按位置读。
