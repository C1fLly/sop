## 这台电脑的工具规矩（SOP 工具包装的，机器级，和项目无关）

- 所有开发工具都装在 `~/tools` 下的固定位置，不占系统盘；不要往别的地方另装一份。
- Python 只用 uv（`~/tools/uv`）：建环境、装依赖、跑脚本都用 `uv`，不用 `pip install`、不用系统的 Python 装包。
- Node 只用 nvm（`~/tools/nvm`）加 pnpm：装依赖用 `pnpm`，临时跑一个包用 `pnpm dlx`；不用 `npm install -g`、不用 `npx`、不用 yarn。
- Docker 是免管理员的那一种，装在 `~/tools/docker`。不要加 `sudo`；不要安装、升级、卸载或改动 Docker 本身和它的设置；不要删数据卷。Docker 出了问题就停下，把看到的报错告诉用户，不要自己修。
- 例外：环境迁移（`sop machine migrate`）是用户本人发起、逐样选择、最后再确认一次的操作，由工具包的脚本执行；它会按用户的选择卸掉旧的 Docker、删掉用户明确说不要了（或者已经带走并核对过）的数据卷。这不算违反上一条。AI 自己不要发起、也不要代替用户做这件事。
- 要输管理员密码的事（`sudo`）不要自己做，先停下告诉用户要做什么、为什么。
