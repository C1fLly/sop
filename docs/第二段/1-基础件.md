# 第二段第 1 步：基础件（根目录、Git 封装、项目锁、端口登记）

2026-11-18。

## 做了什么

- `kernel/paths.py`：固定位置（4.3）。工具包的根目录默认 `~/tools/sop`，可以用 `SOP_HOME` 换：自测一律放在 `/tmp/sop-test/` 下的临时根目录里，不碰真的 `state`、`config`。项目名只许小写字母、数字、`-`。复用 SSH 连接的通道文件目录 `$XDG_RUNTIME_DIR/sop/`，权限 700（6.2 第一条）。
- `kernel/gitx.py`：特权侧执行 Git 的唯一入口。总是写明仓库在哪；关掉钩子；路径不转义；去掉会把 Git 引到别处的 `GIT_*` 环境变量；推送、取回经 `ControlMaster` 复用连接，通道文件在上面那个目录里。
- `kernel/locks.py`：项目锁（8.4）放在 `~/tools/sop/state/<项目名>/sop.lock`，用操作系统的文件锁，进程怎么退出都会自动放开；拿不到时提示「另一个窗口正在推进……这个窗口只能看」，并写明是哪个进程、什么时候开始的。
- `kernel/ports.py`：端口登记（5.5）在 `~/tools/sop/config/ports.json`，读写时上锁；每个工作目录一段 10 个，从 20000 起；分配前再试一下端口是不是真的空着。

## 结果（7 项测试全部通过）

| 验收项 | 测试 | 结果 |
|---|---|---|
| 同一个项目开两个 `sop`，第二个只能看（8.4） | 一个进程拿着锁，另一个去拿 | 拿不到，提示「只能看」，带着前一个的进程号；别的项目照常拿得到 |
| （补的）`sop` 被强制结束后锁不会卡死 | 拿着锁的进程被 `kill -9` | 锁马上放开 |
| 两个项目的 `sop` 同时分配端口不打架（5.5） | 4 个进程（两个项目各两个）同时各分 6 组 | 24 组，没有一个端口重复 |

## 没做的

- 「换了电脑、日志里有别的电脑的步骤开始而没有结束」时先问小白（8.4 最后一句）：要事件日志，第 2 步之后的引擎里做。
