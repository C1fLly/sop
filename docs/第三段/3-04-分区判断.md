# 3-04 体检：分区判断

2026-11-19。没调用 AI，没花钱，没开虚拟机，没动这台电脑（本机只读地跑了一遍 `lsblk`、`findmnt`）。

## 做了什么

- **`machine/disks.py`：体检里「主目录在哪个分区」这一项**（设计书 4.3）。只读，只跑 `lsblk -J` 和两次 `findmnt -J -T`（系统 `/`、主目录各一次），不格式化、不挂载、不改动任何分区。
  - **比的是底下实际的分区，不是名字。** 系统和主目录各自挂的设备，顺着加密层、逻辑卷、RAID 往下找到真盘上的分区；整块盘不分区直接用的，整块盘算一个分区。btrfs 子卷的来源名带 `[/@home]` 这种后缀，去掉再找。两边的分区完全一样算同一个，完全不相交算不同，有一部分重叠（跨几个分区的逻辑卷）或者有一边在磁盘列表里找不到（ZFS、内存盘、网络盘、回环设备），一律「看不出来」，不猜。
  - 结论四种：第一种「主目录不在系统盘上」、第二种「只有一个能用的 Linux 分区」、第三种「主目录在系统盘上，另有能用的分区」（列出是哪几个、什么格式、挂没挂上），和「看不出来」（写明原因）。
  - 「能用的 Linux 分区」：真盘上、Linux 格式（ext2/3/4、xfs、btrfs、f2fs 等）的分区。不算：Windows 的分区（ntfs、vfat、exfat、微软保留分区）、系统自己在用的（`/`、`/boot`、`/boot/efi`、`/efi`、交换区）、系统和主目录所在的分区、移动盘、内存盘和回环设备。
  - 移动盘按接口类型认（usb、火线），不靠「可移动」标记；标了可移动的也算移动盘。系统或主目录本身在移动盘上的，如实提一句。
  - 加密了没打开的分区看不出里面是什么，不算进去，在报告里提一句。
  - 老版 `lsblk`（2.37 以前 `mountpoint` 是一个字符串、`rm` 是 "0"/"1"）也认。
  - `describe()` 给出几行大白话，3-06 的体检报告直接用；`python -m machine.disks` 能单独跑一遍看结果。
- 没有加新命令：`sop machine doctor` 是 3-06 的事。

## 结果

- 新加单元测试 `tests/unit/test_machine_disks.py` 14 项，全部通过。任务要的 9 种都有：两个分区、一个分区（带 `/boot`、`/boot/efi`、交换区）、第三种、加密加两个逻辑卷（判成第二种，不是试验原型会误判的第一种）、btrfs 两个子卷（同上）、整盘不分区（主目录在整块盘上；另一块整盘没用上）、USB 硬盘报「不可移动」、双系统、认不出来（ZFS、内存盘、网络盘、列表里没有、系统在回环设备上、逻辑卷跨分区部分重叠、什么都没查到）。另有：加密逻辑卷但主目录在另一块盘上（第一种）、没打开的加密分区、挂在 `/data` 的分区算「另有」、老版 `lsblk` 写法、系统在移动盘上、用假命令走一遍 `collect()`（只跑了三条只读命令）、命令跑不成或不存在时「看不出来」、在跑测试的电脑上只读查一遍。
- 本机只读跑了一遍：「合格：主目录不在系统盘上。系统在 /dev/nvme0n1p5；主目录在 /dev/nvme0n1p6。」和实际相符（这台电脑盘上还有 Windows 的两个 ntfs 分区和一个微软保留分区，没被算进去）。
- 全部自测：做之前单元测试 54 项、流程沙箱 22 个、总检查 62 个样例全过；做之后单元测试 68 项（多了这 14 项），其余一样，全部通过。

## 没做的

- 样例都是照 `lsblk` 的格式手造的，只有本机这一种是真输出。「加密加两个逻辑卷」「btrfs 两个子卷」在虚拟机里真造出来判，是 3-37 的事；桌面版选「加密」装的真实例子是 3-36。到时候如果真输出和手造的不一样（例如加密层、逻辑卷的路径写法），在那里补。
- 剩余空间提醒是 3-05，体检报告是 3-06。
- 内置存储是 eMMC 的电脑（接口类型 mmc）：没有当成移动盘，因为不少便宜笔记本的系统盘就是它；这样插在读卡器里的 SD 卡如果也报 mmc、又没标可移动，会被算成「另有分区」。只影响第三种的那一句提示，不影响合不合格。没有机器可试。

## 和设计书的出入（留给 3-48 并入）

- 4.3 只写了排除 `/`、`/boot`、`/boot/efi`、交换区；代码另外排除了 `/efi`（有的装法把 EFI 分区挂在这里），也不算内存盘（zram）、回环设备。
- 「看不出来」的几种情况写进 4.3：逻辑卷跨几个分区、和对方部分重叠；主目录或系统不在真盘上（ZFS、网络盘、内存盘、试用盘）。
- 没打开的加密分区不算「能用的分区」，只提一句。
- 移动盘的接口类型定为 usb、火线（ieee1394）；mmc 不算（上面「没做的」第 3 条）。
