# 3-06 体检：工具位置和体检报告

2026-11-19。由主控窗口派出的子代理做。没调用 AI，没花钱，没开虚拟机。本机只读跑了两遍 `sop machine doctor --readonly`（第一遍动了 Pi 安装目录的修改时间，见「自己出的错」）。

## 做了什么

- **`machine/locate.py`：工具在哪**（设计书 4.3「合格」、10.1）。
  - 核对规定位置：按 `tools.toml` 逐样跑检查命令，分「合格」「版本不够」「还没装」三种。系统软件包另外写出命令实际在哪（`/usr/bin/git`）。
  - **另有一份不在规定位置的**：工具包自己装的那 7 样（uv、nvm、Node、pnpm、gh、Docker、wt），按命令名在 PATH 里找，再看别的装法常放的位置（`~/.nvm`、`~/.local/bin/uv`、`/usr/bin/gh`、`/var/lib/docker` 等）。解开链接后在规定位置里面的不算（本机 `~/.local/bin/wt` 指向 `~/tools/wt/wt`，不算另一份）；同一份经不同链接找到只列一次；在前面另一份目录里面的（`~/.nvm` 里的 node、pnpm）写「在 ~/.nvm 里面，大小算在那边」，不重复算。每一份写明在哪、占多大（按实际占的磁盘算，和 `du` 一样；不跟链接、不跨文件系统、硬链接只算一次；没权限看的地方写「至少」）、占不占系统盘（按文件系统算，和 3-05 的剩余空间提醒一致）。
  - **AI 工具**（Claude Code、Codex、OpenCode、Pi）：PATH 里找，找不到再看官方装法的默认位置；记下位置、解开链接后的实际位置、版本。查版本跑 `<命令> --version`：HOME 和 XDG 几个目录指到现建的临时目录、环境变量只留 PATH 和语言（不带任何密钥），**有 bubblewrap 时再套一层「整个系统只读、只有临时目录能写」**；bubblewrap 没装或起不来时不套（新电脑上体检在安装之前）。
- **`machine/doctor.py` 和 `sop machine doctor`**：一份大白话报告，六项：结论、主目录在哪个分区（3-04）、剩余空间（3-05）、基础工具、AI 工具、系统组件（3-05）。
  - 结论里分「还没装好」（基础工具不合格）和「要注意」（看不出分区、剩余空间不够、往终端塞按键没禁用、一个 AI 工具都没找到）。另有一份不在规定位置的只说「不算不合格，也不挡流程」，指向 `sop machine migrate`。
  - 退出码：基础工具全部合格 0，有没装好的 1（报告照样出）。
  - 登记：基础工具和 AI 工具的位置、版本记进 `config/tools.json`（一次上锁写完；真实 AI 演练写的版本 `drilled_version` 留着；清单外的项不动）。AI 工具登记里有演练版本且和现在的不一样时，报告提醒重跑演练。
  - **系统组件的版本体检不记**，只说哪几样和上次登记的不一样。理由：体检要是记了，系统升级后先跑一次体检，`sop` 启动时就看不出变化、跳过了隔离自检（3-07 的前提）。3-05 在 `components.record` 的说明里写的是「体检调用」，改成了「只在隔离自检通过之后调用」。
  - `--readonly`：只看不记，一个文件都不写（连 `config` 目录都不建）。
- **`tools.toml`**：加了两个可不写的字段 `command`（命令名）、`elsewhere`（别的装法常放的位置），清单读的时候检查写法；系统软件包不许写 `elsewhere`。**改了一处 3-03 的错**：Docker 的检查命令写的是 `~/tools/docker/docker`，免管理员 Docker 的程序实际在 `~/tools/docker/bin/` 下（3-05 的 `rootlesskit` 路径也是 `bin/`），本机按旧的写法会报 Docker「还没装」。
- `config.py` 加了 `tool_entry`、`record_tools`（一次登记好几样）；`sop machine` 的帮助里 doctor 改成做好了。

## 自己出的错

- **第一遍本机跑动了一处东西**：那时查 AI 工具版本只把 HOME 指到临时目录，没套只读的那一层。Pi 的启动脚本按它自己的位置（不按 HOME）把 `~/.pi/agent/install` 传给程序，跑 `pi --version` 时这个目录的修改时间变成了 2026-11-19 13:35:00（目录里的文件和文件的时间都没变，多半是建了又删了一个小文件）。原来的修改时间没记下来，没法照原样改回去，就没动它。之后改成有 bubblewrap 时套一层「整个系统只读、只有临时目录能写」，第二遍跑前后主目录下没有任何变化。事先用 bubblewrap 只读试过四个工具的 `--version` 都正常，但当时只看了临时 HOME 里写了什么，没看安装目录，所以漏了。
- 3-03 写的 Docker 检查命令路径不对（`~/tools/docker/docker`），这次本机跑之前看目录发现，改成 `bin/docker`。
- 第一次在临时 HOME 里试跑时，dbus-user-session 那行写成了「系统软件包，系统软件包」，改了。
