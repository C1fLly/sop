## 做了什么

### M6 准备受限环境（`machine/syscheck.py`、`runner/docker/selftest_docker.py`）

- **隔离自检改成两份依次跑、都过才算过**（3-07 留下的）：本机那份 `runner/selftest.py`，加专用 Docker 那份 `runner/docker/selftest_docker.py`。前一份没过也接着跑完后一份，不符合的行一起列出来；两份的汇总行合成一行「隔离自检：N 项，M 项不符合」，有一份没跑完（例如专用 Docker 起不来）就加一句「有一份没跑完，没算在里面」。`SOP_SELFTEST_CMD` 还是换成一条（流程沙箱用）。
- **`prepare()` 就是 M6**：不管登记里有没有、变没变，都跑一遍隔离自检；通过了把自检**之前**查到的系统组件记进 `config/system.json`（和 3-07 一样的记法），所以装好机器之后第一次推进流程不用再自检；没通过登记不改、指向 `sop repair`。和 3-07 的 `gate()` 共用一把锁。`python3 -m machine.syscheck` 直接跑它（3-12 的 `sop machine setup` 做好之前虚拟机里用）。
- **专用 Docker 那份能在小白电脑上跑了**：原来是第二段的虚拟机试验脚本，假项目建在 `~/Project/sopdk-fixture`、跑完留着 `state/sopdk` 和通道目录里的假通道文件。改成：假项目建在 `/tmp` 下现建的目录；跑完（不管过没过、出没出错）把假项目、`~/tools/sop/state/sopdk`、假通道文件都删掉，临时服务停掉；`state/sopdk/ai-state` 已经有东西（万一真有叫 sopdk 的项目）就不动、停下。拉镜像的代理从网络设置里取（`SOPD_PROXY` 给了就用它）。留下的只有这个专用 Docker 的数据 `~/tools/docker-sop/sopdk`（拉下来的 `debian:stable-slim`，约 115 MB，下次自检不用再拉）。

### M7 安装全局规则（`machine/globalrules.py`、`machine/global-rules.md`）

- 规则的原文在 `machine/global-rules.md`：只有机器级的（工具都在 `~/tools`；Python 只用 uv；Node 只用 nvm 加 pnpm、`pnpm dlx`；Docker 是免管理员的、不加 sudo、不装不改 Docker、不删数据卷、出问题停下告诉用户；要 sudo 的事先停下说），**写明环境迁移是例外**（用户本人发起、逐样选、再确认，由工具包的脚本执行，AI 自己不发起）。不含流程的规则（那些在项目的 `AGENTS.md` 里）。
- 写进各工具的全局规则文件，一段带开头结尾标记（HTML 注释，不显示）：
  - Claude Code：`~/.claude/CLAUDE.md`（设了 `CLAUDE_CONFIG_DIR` 就在那下面）
  - Codex：`~/.codex/AGENTS.md`（`CODEX_HOME`）；同目录有不是空的 `AGENTS.override.md` 时 Codex 只读那一份，所以那一份里也写
  - OpenCode：`~/.config/opencode/AGENTS.md`（`XDG_CONFIG_HOME`）。**它自己的这一份不存在时不新建**：官方文档说没有它时 OpenCode 读 `~/.claude/CLAUDE.md`，一旦新建，用户原来写在 `~/.claude/CLAUDE.md` 里的规则对 OpenCode 就不生效了。已经有了就写进去；Claude Code 的规则文件被 `CLAUDE_CONFIG_DIR` 挪走时也新建（退路里没有这一段）
  - Pi：`~/.pi/agent/AGENTS.md`（`PI_CODING_AGENT_DIR`）
- 规矩和终端启动文件那一段一样（把 `shellenv.py` 里加段、读、写的几处抽成能换标记的函数，两边共用）：段落外的字一个不动；已有就原地换、没有就加在末尾；标记对不上（只剩一头、两段、结尾在前）不改、明说，别的工具照样写；内容没变不写、修改时间不动；是链接就写到它指的文件；权限照旧；新建的目录每一层都是 0700；先写临时文件再换名；不是 UTF-8 不改。
- 出口检查 `check()`（`python3 -m machine.globalrules --check`）：每个工具**实际会读到的那一份**里有且只有一段、和工具包里的一字不差（OpenCode 没有自己那份时查 `~/.claude/CLAUDE.md`）。只读，不建任何东西。
- 只碰这几个规则文件，不碰各工具的设置、密钥、会话记录。
