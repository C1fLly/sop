# 用户的原始要求

共 14 条：最初的 12 条，加上第三轮审查时补的 2 条。原文照录。出处：2026-11-16 他发给第二轮独立审查窗口的那段话（他本人写的）。2026-11-17 从 Claude Code 在本项目下的历史会话里找回，存在这里以免再丢。

背景（他的原话）：我没有编程基础。我要一套工具，让我指挥 AI 开发大型企业生产级项目，我只验收行为、不看代码。

1. 能在任何新电脑（Ubuntu）上使用，包括开新项目、继续旧电脑上的项目
2. 融入 mattpocock/skills，开发主链是 grill-with-docs → to-spec → to-tickets → implement 或 implement-spec
3. 用裸仓库，使用 wt 工具（~/tools/wt）
4. 工具安装位置和项目位置固定
5. 同一台电脑可以多个项目并行
6. 通用多端：前后端分离、小程序、App
7. 能用 shell 或 Python 脚本审查的，不得手动做或交给 AI 做
8. 设计本身和每一步执行都要单一职责、边界清晰、模块化、循序渐进
9. 两套后端技术栈都支持，之后能轻松增补其他技术栈
10. 包含原型和前端；长期开发不能出现偏差
11. 覆盖从需求到上线运维；没有专业技术人员兜底
12. 让 AI 精准、高效、高质量地开发

13. 不得更改融入的skill
