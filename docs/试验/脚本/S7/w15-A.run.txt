## 做了什么

- **标记已离职**：老板菜单新增「把员工标记为已离职」，带一步确认；没有老板身份、名单上没有这个人、或已经是已离职的，规则层都拒绝。
- **已离职之后**：不出现在「我是员工」和代登记的可选名字里，登记和代登记在规则层被拒绝；新加的人不能与他重名。
- **历史保留**：他以前的请假单老板仍可查看，待审批的仍可批准或驳回，已批准的仍可作废。
- **月度统计**：当月有已批准请假天数的已离职员工照常列出并标「（已离职）」，为 0 的不显示；在职员工为 0 仍显示。
- **人员名单和各清单**：已离职的名字后面都带「（已离职）」。

## 两处你可能想知道的取舍

- **已离职员工自己也不能再查看或撤回请假单。** 工单只写了不能登记，这是按规格「员工操作只需指明是哪一名在职员工」做的。后果是他名下待审批的请假单只能由老板批准或驳回，不能撤回。
- **顺手防了一个会让工具崩掉的情况**：月度统计下方的待审批清单原先从统计行里取名字，已离职且当月没有已批准请假的人会找不到名字，现在改从人员名单取。
